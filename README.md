# cellular-automaton-shader
This repository will contain a number of short shader scripts that showcase a number of  cellular-automations that use multiple seeds that compete with each other in a given environment. It is possible to implement any cellular automaton via simple shader logic that can run any gpu. Cellular automations can have more than one starting seed, that compete each other in a given envrionment. Also it is possible to assign simple logic rules to each seed to change the seeds behaviour. The typicall known conways game of life only uses one seed with rather simple instruction.
